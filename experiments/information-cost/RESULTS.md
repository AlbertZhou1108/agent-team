# 信息层方案可行性实验

日期：2026-10-23。结论：信息投影与正文引用具备实现切入点；尚未证明真实 token、费用或交付质量收益。生产逻辑未修改。

## 方法

使用真实 Bus、SQLite 存储、工作项管理与 read 工具；宿主为内存 fake，不访问真实团队、不调用模型。投影和引用解析器仅存在于实验测试文件，不接入生产。合成负载故意放大长日志和长历史，用于检验增长趋势，不代表用户实际团队分布。

运行：

```sh
node --disable-warning=ExperimentalWarning --test experiments/information-cost/feasibility.test.mjs
node --disable-warning=ExperimentalWarning --test test/collaboration.test.mjs test/tools.test.mjs
```

实验 5/5 通过；现有定向回归 6/6 通过。首次实验撤权断言预期为原型错误，实际被现有 Store.member 更早拒绝；修正断言后通过。测试没有修改生产路径，因此回归通过不能证明新方案集成后兼容。

## 证据

| 实验 | 观测 | 判断 |
| --- | --- | --- |
| 50 条长日志消息 | 原 read 2,191,120 B；引用与预览 60,651 B，初始响应减少约 97.2% | 长正文是可控制的输入来源；比例仅适用于此合成数据 |
| 长正文完整展开 | 原字符串 JSON 43,543 B；引用及分页响应累计 45,544 B | 全展开会增加传输量；不得仅用初始响应降幅推断节省 |
| Unicode 与中部错误 | 分页拼回严格等于原文；预览缺少中部 E_MIDDLE | 不能把首尾预览当完整证据；字符偏移约定必须固定 |
| 80 个工作项 | 完整状态 313,899 B；事件游标推进后仍 147,599 B；rules 317,911 B | 现有事件分页不能约束全量快照和注入 |
| 概况投影 | 10 条工作项概况及契约/状态 1,673 B，权威 read 未被修改 | 证明投影可以很小；不证明这个概况足够完成任务 |
| 引用授权 | 跨团队拒绝、移除成员拒绝、内容变化后旧哈希拒绝 | 现有数据库可承载正文引用，communication 无需新增文件工具；原型未覆盖 endpoint key 校验，生产必须保留现有入口认证 |
| 分页 | 两团队交错 seq、翻页中追加消息，既有 read 无丢失/重复 | 可复用消息游标机制；不等于已实现状态增量协议 |
| 宿主切入点 | 真实 runEndpoint 向 fake host 分别传递 prompt/instructions，工具集合保留 | 可在装配前投影；未验证真实宿主缓存、规则更新和会话兼容 |

字节数是 JSON/UTF-8 序列化测量，不是 token；展开累计也不包括宿主重复发送历史、读取请求和推理输出，不能作为真实费用上界或下界。

## 方案修订

1. 先做真实状态概况、定向详情与规则拆分；不先建设通用磁盘外置系统。消息原文已在数据库内，按 ID/版本范围读取即可。
2. 长文本预览只用于定位，存在关键判断时必须读取相关原文；特别测试中部错误、被后续推翻的决定及权限约束。输入任务本身不做机械裁剪。
3. 引用使用有界字符范围或行范围，并明确 Unicode 约定；本实验采用 JS UTF-16 offset，拼接无损不代表每页都不会切开代理对。生产应选行范围或 Unicode code point 边界。
4. 不宣称小概况具备语义充分性。实施前补包含契约约束、阻塞、旧成果、失效审查和跨目标历史的金标准任务，再比较原始与投影信息的决策结果。
5. 延后项目索引、自动交接摘要、宿主内部输出外置与持久状态游标；本实验未验证它们。
6. 总收益以任务全程 token、展开次数、回合和质量共同评估，尤其对必须全文阅读的任务保留直接读取路径。

## 尚未通过的验证门槛

- 原生 Codex/DSH/其他适配器的同会话规则更新、Panel 与 MCP/dynamic tools 一致性。
- 新接口端到端身份认证、控制者交接、目标切换与并发修订、删除/引用生命周期。
- 稳定前缀的真实缓存效果；宿主原生工具输出可控性。
- 真实任务金标准、质量保持、实际 token/费用对照。

因此适合进入第一阶段受控实现，不适合把完整方案判为已验证或直接全量上线。
