# Agent Team 前端设计指南

本文是 Agent Team 前端的**本仓专有设计事实源**（产品气质、五维外观架构、全贴边壳层、动效契约与业务交互不变式）。通用的视觉排版、无障碍与 Web API 实践交由全局前端 Skills 承载，本文不再重复教科书常识；具体代码级原语与门禁速查见 [skills/design-system/SKILL.md](../skills/design-system/SKILL.md)。

前端采用 Vue 3、Tailwind CSS 与 shadcn-vue。新增页面、组件与外观能力均须遵循本文与 `scripts/check-design.mjs`；业务语义与数据契约由对应业务文档定义。

## 产品气质（Quiet Instrument · 纯黑碳灰）

Agent Team 是组织多 Agent 协作、推进任务与审视执行轨迹的精密工作台。界面安静、清楚、可信，优先服务「我正在看什么、当前进展怎样、接下来做什么」三个判断。

- **全贴边无缝分栏（方案 A）**：所有预设与材质（默认实色、毛玻璃、纸质、活力）统一收敛为全贴边分栏（`--component-sidebar-inset: 0px`、`--component-panel-gap: 0px`），取消外圈留白与三张浮空大卡片，以 `1px` 发丝分割线（兼拖拽把手）与表面明度阶梯建立分区。
- **校准明度阶梯（无彩色中性灰）**：深色默认采用零偏色碳黑 + 深炭灰分层——主工作面 `#0D0D0E`（`--card`）最沉，左右分栏 `#141415`（`--background`，`nav-panel`/`context-panel`）对称微亮半档，卡片/输入框/浮层 `#1B1B1E`（`--secondary`/`--popover`），悬停/选中高亮 `#252529`（`--accent`）；浅色同步去蓝灰，采用纯中性白灰（左右栏 `#F5F5F6` → 主区 `#FFFFFF` → 卡片/输入 `#EFEFF1` → 悬停 `#E6E6E9`）。
- **低眩光身份色**：成员与团队徽标采用 OKLCH 等明度 6 色 Tinted Identity Badges（柔底 + 高对比前景），替代高饱和实心彩虹球。

## 统一外观模型（五维配置）

公共组件配置以**样式、排印、材质、行为、布局**五维为实现模型。用户通过明暗模式、配色主题、材质、动效和界面密度调节外观；阅读偏好独立保存，设计预设可提供排印默认值，但不覆盖用户阅读设置。

| 维度 | 负责什么 | 选项方向 | 不负责什么 |
| --- | --- | --- | --- |
| 明暗模式 | 亮度、对比度及浅深色解析 | 浅色、深色、跟随系统 | 色彩风格、材质、动效 |
| 配色主题 | 主色、表面颜色及状态语义色 | 经典、海雾、松林、紫雾、暖纸、跃彩及自定义包 | 透明模糊、动画节奏、布局 |
| 材质 | 表面底色、模糊、纹理、边缘、圆角与按压物性 | 默认实色、毛玻璃、纸质、活力 | 业务状态、文字尺寸、动画过程 |
| 动效 | 状态变化的时长、缓动、弹性与减少策略 | 跟随系统、减少、简洁、柔和、灵动 | 业务时序、请求完成时间、静态配色 |
| 界面密度 | 行高、间距、容器留白与控件尺寸 | 紧凑、标准、宽松 | 正文缩放、信息隐藏、功能删减 |

> 现状核对日期：2026-11-25。五维解析、四套设计预设（默认 / 毛玻璃 / 纸质 / 活力）、独立阅读偏好、自定义主题上传校验与首帧快照均已实现；不得因扩展维度改变老用户已有选择。

### 明暗模式、配色主题与材质

- 明暗模式先解析为浅/深色，再读取主题包语义颜色。业务代码只消费语义 token，不感知主题名，也不写主题分支；自定义主题上传受 `TOKEN_KEYS` 与取值白名单约束，不能携带任意 CSS 或脚本，不得随意给主题上传格式新增必填键。
- 表面角色固定为 5 个已注册角色（`nav-panel` / `context-panel` / `action` / `input` / `overlay`），由 `<Surface role="...">` 写入、共享材质表（`materials.ts`）驱动，页面不自写模糊、阴影或纹理。
- **贴边与浮层边界**：`nav-panel` 与 `context-panel` 全贴边零外圆角零外投影；`overlay`（弹窗/下拉/提示/回底按钮）保留 `--component-panel-radius` 与独立浮层层次；毛玻璃做静态高斯模糊加 Vibrancy（不支持时自动回落同配色实色）；纸质保留哑光纸纹与内部薄截面阴影，外层分栏同样全贴边；活力保留大圆角内件与明快配色。

### 动效契约与编排守则

- **同源解析**：用户明确选择优先，仅「跟随系统」响应 `prefers-reduced-motion`，统一收口于 `<html data-motion>` 与 [motion.ts](../web/src/shared/motion.ts)。
- **三档面积时长 × 节奏系数**：`fast 150ms`（微反馈/悬停/按压）、`normal 220ms`（浮层/折叠/内容出现）、`slow 320ms`（分栏列宽/移动抽屉），统一乘 `--motion-pace`（`simple 1` / `soft 1.35` / `lively 0.7`）。
- **曲线校准**：`--motion-ease-out` 采用强减速 `cubic-bezier(0.23, 1, 0.32, 1)`，浮层进出均弃用发黏 `ease-in`；`lively` 档弹性过冲收敛至 `cubic-bezier(0.22, 1.18, 0.36, 1)` 且仅用于微反馈与浮层进入，大面积分栏与折叠（`standard`）保持无过冲；移动端抽屉采用 `cubic-bezier(0.32, 0.72, 0, 1)` 原路对称退回。
- **语义别名强约束**：业务组件只消费 `--component-feedback-duration` / `--component-disclosure-*` / `--component-content-*` / `--component-overlay-*` / `--component-layout-*`，严禁直读 `--motion-*` 或手写字面量时长（由 `scripts/check-design.mjs` 强制）。
- **刻意不动（高频禁区）**：不做团队/路由/设置子页整页切换过渡、不做高频列表项 stagger、不做流式消息追加重复入场、不改 Toast 内建节奏、拖拽分栏 `.is-resizing` 期间归零列宽过渡。
- **合成层与指针门控**：默认仅动画化 `transform` / `opacity`（折叠走 `grid-template-rows`，分栏收起走 `grid-template-columns`），严禁 `transition: all`；带位移/缩放/把手的 hover 效果须加 `@media (hover: hover) and (pointer: fine)` 门控；`html[data-motion='reduced']` 关位移与循环动画但保留清晰静态状态。

## 本仓页面骨架与业务交互不变式

1. **三栏职责与单层边界**：左轨/团队栏定位与导航、中央承载当前主要任务、右栏提供上下文详情；左右栏收起按钮底部对齐，空文件夹拖入虚线框仅在拖动团队时出现。容器已有可见边界时内部不再套卡片（`check-design.mjs` 静态拦同模板卡片嵌套）；同类列表用分割线与左侧 `2px` 选中标代替逐行套卡。
2. **首页与遥测布局**：团队首页空态「未读 / 执行活动」自动收薄为 `~48px` 状态带，将「进展摘要」置于首屏核心位；遥测 `MetricCard` 无论是否带进度条保持统一 `22px` 主数值基线，成员开销排行用无框分割线列表。
3. **会话工作区与实时流**：Panel Agent 与团队共用同一会话工作区（2 行紧凑顶栏、主控与成员统一左缘对齐，由 Tinted 头像与发件人名称区分角色，无气泡左侧色条）；Panel Agent 主会话以本次服务启动为显示分界（不重置模型会话），历史消息在只读分页中查看；并发流反馈由状态栏与拓扑胶囊承载，实时更新不打断向上阅读的历史位置。
4. **归档与破坏性操作**：归档团队从业务导航与统计隐藏，仅在设置页查看只读快照、恢复或永久删除；归档保存快照、查看时按需生成摘要、恢复时清理快照。
5. **帮助说明与通知分工**：能由标题、状态与结构直接表达的内容不加常驻解释句，低频复杂背景放入共享 `HelpPopover`；同一事件只用一处主要反馈位置，Toast（`vue-sonner`）与内联错误不机械双弹；待处理互动卡在当前视口可见时不重复通知，处理后及时撤销通知。

## 验收矩阵

改动按影响范围走查（共享基座/壳层变更需覆盖代表性组合，源码检查不替代实机浏览器验收）：

| 验收维度 | 核对要点 |
| --- | --- |
| 外观组合 | 深/浅模式 × 经典与有色主题 × 实色/毛玻璃/纸质/活力全贴边与降级回落 |
| 视口与端 | 桌面 `1440×900`、平板 `900×800`、移动 `430×900`（顶栏不裁切、sticky 栏零漏出）、Electron 自定义顶栏高度 |
| 动效与交互 | `simple` / `soft`（慢放中帧）/ `lively`（无大面积过冲）/ `reduced`（关位移保状态）；连续点击中断与拖拽跟手 |
| 持久化与兼容 | 刷新首帧不闪烁、旧偏好兼容、阅读偏好独立保存、CSP 零拦截报错 |
