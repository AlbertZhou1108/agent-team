# 归档与 Panel 历史记录

已实施的产品规则见 DESIGN.md。团队归档后，常规团队列表、Panel团队关系、首页统计均排除该团队；设置页通过单独的归档元数据列表提供恢复。团队、会话、消息轨迹、互动答复、SSE及RPC入口校验归档状态；HTTP业务请求返回410。恢复保留原有数据。

Panel使用Bus实例启动时的最大panel_messages.seq作为分界，bootId隔离缓存。主会话和未读投影只读取分界后的私人消息；历史页分页读取分界前的所有私人消息，不再按active_team_id筛选。分页每次最多200条，服务端多读一条判断是否还有记录。原宿主session未重置，显示分界不改变模型记忆。
