# 默认实色：元素实现

引用：[元素规格](../element-specifications.md)、[共用实现](README.md)。状态：现有基线；下面列出三类元素的统一目标，不表示所有使用处已达标。参数继承主题和组件库，不固定白色、黑色或一组页面局部色值。

| 元素 | 默认呈现 | 状态与行为适配 |
| --- | --- | --- |
| E-GROUP | 标题和子项使用导航面板的实色环境，不为每组增加独立卡片 | 共用开合实现；指示器和内容按同一节奏转移；焦点、拖放提示不依赖开合动画 |
| E-NAV | 默认导航行不额外堆叠表面 | current 使用持续状态底面与非纯颜色位置提示；selected 使用独立选择提示；悬停/按下叠加共享状态层，焦点边界独立保留 |
| E-CONTENT | 数据卡片与独立目录条目均有显式 reading 底面及必要边界，解决一种实色、一种透明的偶然差异 | Card 与 Item 保留各自结构和尺寸；只有可交互部分产生对应反馈，不把数据卡片默认变成按钮 |

## 已有能力与待完成项

- 已有：solid 的材质角色配方为空，表面沿用主题/组件基线；Card 使用 bg-card；导航当前主要使用 Button secondary 或 Item muted。
- 待完成：current/selected 的共用独立状态配方，团队目录独立底面的接入，以及未分组/置顶的开合迁移。
- 待视觉验证：位置与选择标记的具体形态、状态底面的对比度、Card/Item 并列时的边界层级。不新增未经验证的尺寸或颜色常量。

## 验收

先通过 G1–G4、N1–N5、C1–C4，再验证：

- S1：浅色/深色、经典/有色主题下，current、selected、hover、focus 组合可辨。
- S2：首页数据卡片与目录条目都有清楚底面，但不抹平信息层级和动作差异。
- S3：从其它材质切回时无滤镜、纹理、高光或内联参数残留；系统辅助模式仍可识别状态。

覆盖和结果见[台账](../element-implementation-coverage.md)，不得据文档存在标为通过。
