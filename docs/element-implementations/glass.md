# 玻璃：元素实现

引用：[元素规格](../element-specifications.md)、[共用实现](README.md)。状态：面板光学能力已接入；导航内部状态配方、内容单元的一致表面仍待整改及视觉验证。光学参数的唯一数值来源是 [materials.ts](../../web/src/theme/materials.ts) 和共享 CSS，此处不复制会漂移的数值。

## 三类元素的呈现

| 元素 | 默认呈现 | 状态与行为适配 |
| --- | --- | --- |
| E-GROUP | 标题和子项复用导航父玻璃，不给每个分组增加完整折射面 | 开合结构与实色共用；只按动效策略和材质约束解析节奏；包含当前位置的提示不把分组误标为页面 |
| E-NAV | 默认行保留父面板环境色 | current 采用轻状态层、局部边界与稳定位置标记；selected 用可区分的选择标记；复合状态不堆两层不透明块；focus 不被高光覆盖 |
| E-CONTENT | 首轮方案沿用稳定的 reading 实色底面，数据卡片和独立目录单元都有显式承载面 | 导航/操作玻璃与阅读底面允许不同；可交互部分仍消费共享反馈，正文不参与位移 |

以上导航当前态和内容底面是**待验证方案**，不是已被用户验收的最终画面。位置标记、状态层透明度和局部边界在真实侧栏中验证后进入共享配方。若目录采用轻玻璃，修改本实现说明与共享配方，不修改 E-CONTENT 的定义，也不在 TeamHome 单独叠透明度。

## 回退与其它维度

当前 SVG 背景折射只在代码选定的 Chromium 路径启用；其它引擎保留普通模糊玻璃。CSS.supports 的语法结果不能证明真实折射效果。降低透明度或缺少模糊能力时按现有材质入口回落实色。

减少动态效果不等于降低透明度：前者关闭相应交互动画，后者改变表面回退。明暗、主题和密度仍走各自契约；材质不得改变路由、展开状态、选择集合或组件骨架。每个导航行不额外生成完整的模糊/折射层。

## 验收

先通过 G1–G4、N1–N5、C1–C4，再验证：

- GL1：导航 current/selected/hover/focus 可辨，并保留父玻璃环境感，不出现普通不透明选中色块遮盖整行的突兀层次。
- GL2：数据总览与团队目录的承载层级一致；若使用稳定阅读底面，两者均有底面，不因一个用了 outline 就偶然透明。
- GL3：滚动背景在曲面边缘产生位移，前景文字、输入和菜单操作保持清晰可用；调尺寸后滤镜与表面匹配。
- GL4：浮层开关、实色切换和降低透明度回退无资源或样式残留；非增强路径仍满足共同语义。

原有光学验证不能替代导航选中态和内容表面的新验收，结果见[台账](../element-implementation-coverage.md)。
