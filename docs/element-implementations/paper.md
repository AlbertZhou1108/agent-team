# 纸质：硬朗粗糙的实现

引用：[元素规格](../element-specifications.md)、[共用实现](README.md)、[配置契约](../component-configuration.md)。**状态：2026-11-01 视觉方向定案（用户拍板四项决策）并落进共享配方；数值观感待用户肉眼验收，完整边界验收见覆盖台账。**

## 设计方向

纸质通过不透明承载面、受控纹理、边缘和层次表达材质，不使用透明折射或玻璃镜面高光。物理隐喻：纸是裁切出来的、不透光的、有纤维粗粝感的 sheet，摞在桌面上靠硬投影分层。纸张气质独立于主题配色，不把“纸质”固定等同于米黄色；浅色和深色都应有可读实现。

2026-11-01 定案的四项决策（数值唯一来源是 [materials.ts](../../web/src/theme/materials.ts) 与 [design-presets.ts](../../web/src/theme/design-presets.ts)，此处不复制会漂移的值）：

1. **近直角**：控件 2px / 面板 3px 字面像素，脱离主题 radius 体系 —— 裁切硬边。
2. **颗粒 + 帘纹叠加**：双色调 feTurbulence 噪点（黑/白各一层）+ 前景色横纹。黑粒在浅色纸可见、白粒在深色纸可见，同一份值跨明暗主题通用，不需要 CSS 分支。
3. **硬偏移堆叠投影**：content 面为纸边（0 1px 0）+ 位移投影（2px 2px 0）；面板/浮层为 3px 3px 0。全部用 foreground 低百分比混色，不随主题换色失效。
4. **桌面画布**：paper 的环境层对应物 —— 略深的桌面底色 + 同族噪点（`--component-desk-*`），由 globals.css 唯一一条 paper 段消费到 `.app-shell`；纸张靠桌面衬托“放上去”的层次。

| 元素 | 呈现 | 状态与行为适配 |
| --- | --- | --- |
| E-GROUP | 标题和子项使用同一纸质导航承载面，不给每组堆叠一张纸卡 | 复用共用开合能力；无弹性（spring suppress），风格档只调整允许范围内的节奏；不增加独立折纸动画 |
| E-NAV | 默认项保持平静的纸面 | current 通过局部纸面明度、压印式描边（inset 1px）和位置标记表达；selected 采用独立选择标记；hover/pressed 是同一表面的状态差量；focus 有明确边界 |
| E-CONTENT | 数据卡片与目录条目采用同一纸面基础 | 独立纸面用硬偏移投影区分层级；纹理不覆盖文字、不拦截交互；动作仍由共用交互承担 |

## 实现方式

`materials.ts` 的 paper 配方持有：双色调噪点 + 帘纹的表面纹理、纸边与位移投影（content/panel 两档）、导航压印描边、桌面底色与桌面纹理。`design-presets.ts` 的 paper 预设持有：2px/3px 圆角、标题尺度、简洁动效与禁用按压缩放（无弹性）。`globals.css` 的 paper 段只有桌面消费一条，表面工艺全部走通用变量消费链。共享组件不判断 paper ID；偏好迁移、设置选择、切换清理均已接入；新增纸质未复制组件、页面或渲染器。

按压手感：无缩放（press-scale 1）+ 弹簧压制，作为物性键由 PAPER.components 内化（2026-11-01 起圆角与按压随材质，不在预设差量中）；“纸被压平”类的按下沉降未实现，留待观感反馈后再决定是否进行为契约。

## 验收与未决项

除 G1–G4、N1–N5、C1–C4 外：

- P1：浅色/深色、经典/有色主题中保持纸面气质与清晰信息，不依赖固定纸色 —— 双色调噪点与 token 混色使其结构性成立，仍需主题矩阵抽查。
- P2：current、selected、hover、focus 的组合可辨，不引入折射高光；与玻璃/实色切换后无纹理和阴影残留（配置链整体覆写，结构性无残留，需抽查）。
- P3：长列表、缩放和低能力环境下不因纹理增加明显阅读干扰；辅助模式去掉装饰后仍保留状态。
- P4：无弹性运动约束与用户动效档组合成立；减少动态效果时语义终态相同。

未决：首轮数值的观感认可（噪点强度、投影深度、桌面深浅属共享配方改值）、状态辨识度、辅助模式完整验收。代码已接入与视觉验收完成分开记录。
