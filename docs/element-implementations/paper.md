# 纸质：首轮配置实现

引用：[元素规格](../element-specifications.md)、[共用实现](README.md)、[配置契约](../component-configuration.md)。**状态：2026-11-01 已注册材质与设计预设、接入设置，并验证浅色切换与刷新。视觉参数尚待用户认可，完整边界验收见覆盖台账。**

## 设计方向

纸质通过不透明承载面、受控纹理、边缘和层次表达材质，不使用透明折射或玻璃镜面高光。纸张气质独立于主题配色，不把“纸质”固定等同于米黄色；浅色和深色都应有可读实现。

| 元素 | 候选呈现 | 状态与行为适配 |
| --- | --- | --- |
| E-GROUP | 标题和子项使用同一纸质导航承载面，不给每组堆叠一张纸卡 | 复用共用开合能力；材质运动约束拟采用无弹性，风格档只调整允许范围内的节奏；不增加独立折纸动画 |
| E-NAV | 默认项保持平静的纸面 | current 通过局部纸面明度/压印式边界和位置标记表达；selected 采用独立选择标记；hover/pressed 是同一表面的状态差量；focus 有明确边界 |
| E-CONTENT | 数据卡片与目录条目采用同一纸面基础，按用途建立必要层级 | 独立纸面可用轻边缘和受控投影区分；纹理不得损害正文、数据和代码的阅读；动作仍由共用交互承担 |

## 实现方式

`materials.ts` 的 paper 配方提供角色纸面、细纹理、导航状态与无弹性约束；`design-presets.ts` 的 paper 预设组合较小圆角、标题尺度、简洁动效与导航内边距。共享组件消费相同参数，不判断 paper ID。偏好迁移、设置选择、切换清理均已接入。新增纸质未复制组件、页面或渲染器。

纹理和边缘资源由共享材质层拥有，不复制到各页面；重复纹理不得覆盖文字或拦截交互。具体粗糙度、纹理强度、投影、状态明度和位置标记须通过样例再确定。若颜色/边界已经足够表达层级，不为追求拟物额外堆装饰。

## 验收与未决项

除 G1–G4、N1–N5、C1–C4 外，拟增加：

- P1：浅色/深色、经典/有色主题中保持纸面气质与清晰信息，不依赖固定纸色。
- P2：current、selected、hover、focus 的组合可辨，不引入折射高光；与玻璃/实色切换后无纹理和阴影残留。
- P3：长列表、缩放和低能力环境下不因纹理增加明显阅读干扰；辅助模式去掉装饰后仍保留状态。
- P4：无弹性候选运动约束与用户动效档组合成立；减少动态效果时语义终态相同。

未决：视觉层次强度、状态辨识度、性能和辅助模式的完整验收。代码已接入与视觉验收完成分开记录，不因配置可运行就宣称 P1–P4 全部通过。
