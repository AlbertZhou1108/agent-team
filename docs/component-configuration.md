# 公共组件配置与设计预设

全站收敛按[功能组件分析](frontend-functional-components.md)识别使用处与复用层，不以现有标签或视觉相似度划分组件。Disclosure 只是详情开合的一种功能组合，不能代表所有折叠场景。

2026-11-01：用户同意按“配置模型 → 公共组件 → 链路验证 → 玻璃预设 → 第二套预设”推进。本文定义此次实施的契约，不把材质文档当作架构主体。

## 1. 目标与边界

预设是样式、排印、材质、行为、布局五个维度的配置集合。公共组件消费解析结果，业务页面提供内容、独立状态与动作。已有 shadcn 原语直接接入配置，不为传递变量增加无意义包装；侧栏、会话等组合复用原语和共享布局规则。

元素信息由 element-specifications.md 定义，组件配置负责如何呈现，实现说明是预设设计资料，覆盖台账负责使用处与证据。配置范围是组件注册的视觉和转移参数，不包括业务数据、权限、导航目标或执行任意脚本。

## 2. 配置与解析

每个维度有自己的参数键集合，组件、部位和状态通过稳定语义变量消费。默认配置必须完整；预设只填写差量。层次：框架默认 → 预设差量 → 用户对应维度选择 → 环境/能力回退与跨维度适配 → 一次性输出。

- 样式：主题引用、控件/面板形状；颜色仍从现有主题包解析，不改变上传格式。
- 排印：控件、导航、标题排印；用户已有正文/代码阅读偏好继续独立覆盖，不被切预设重置。
- 材质：角色表面、控件及导航状态层的配方，以及已有光学能力的参数。
- 行为：反馈、开合的时长/曲线引用和按压幅度；用户动效选择解析节奏，减少动态效果优先满足无动态呈现；材质约束参与组合。
- 布局：控件尺度、导航内边距、侧栏留白、面板间距和阅读区密度。业务骨架和滚动归属保持一致。

选择设计预设时应用它的外观默认选择；之后调整密度只影响布局，调整材质只替换材质配方，不锁死其他维度。保存组合时保存设计预设引用与当前维度选择；旧组合缺少引用时按已有材质迁移到兼容基线。

单一输出入口对首帧和后续更新共用，重新选择时完整替换变量，避免状态/纹理残留。能力缺失只回退相关效果，不改变请求中的其他偏好。

## 3. 公共组件消费清单

| 模块 | 配置入口与状态 |
| --- | --- |
| Button | 形状、尺寸、控件排印、反馈时长和按压幅度；危险/禁用/加载语义保留 |
| Input / Textarea / InputGroup / SelectTrigger | 控件形状/尺寸/排印、输入表面；内部输入不重复铺材质 |
| SidebarEntry / 主导航入口 | current、selected、contains-current、hover、pressed、focus 分开；状态层和部位标记共用配方 |
| CollapseReveal / Collapsible | 同一开合配置；内容不可聚焦、焦点返回、指示器随展开状态变化；不按材质复制结构 |
| Card / 内容目录 | 共用内容表面参数；Card/Item 保留不同内容结构 |
| Surface / 左右侧栏 / 会话面板 / 浮层 | 表面角色配方、共享形状、间距；复用上述控件和原有业务插槽 |

优先覆盖已有真实使用处，不宣称所有任意 HTML 或第三方内部节点都已可配置。后续公共组件沿相同接口接入。

## 4. 预设与能力

### 预设独立性（2026-11-01）

玻璃选中状态第二轮：针对“轮廓太硬、组件各自呈现”的反馈，增加共享 selection-bg/fg/shadow 配方，由玻璃导航 current、分段选项 on、页签 active 引用。取消高对比选中描边，采用浅色 90% card / 深色 10% foreground 的半透明面、较弱内侧亮边及轻阴影；导航位置标记和键盘焦点继续独立。浏览器在经典深色下核对三类元素的实际背景、阴影、透明边框与 8px 圆角一致，并检查浅色。仅代表这些状态消费者，不宣称所有列表选择均已覆盖。其他预设不引用玻璃 selection 配方；页签保留通用默认映射。

玻璃选择状态首轮打磨：ToggleGroup 增加共享 segmented 呈现，设置页的设计预设、明暗、动效、材质、密度及阅读选项接入。公共组件消费 choice-track/choice-selected 等登记参数；玻璃材质配方提供底座、明暗选中面、轮廓与轻投影，玻璃设计预设提供 4px 底座留白/间距。未选中项保持平静，悬停不覆盖选中反馈，键盘焦点有独立外圈；不添加勾选。其他位置的默认 ToggleGroup 不变，纸质/实色继承普通选择配方。材质选项统一三列排列，避免单个选项落到第二行。

浏览器验证：经典主题、1280×720，浅色/深色玻璃；选中与未选中底面、边界均可区分；切纸质后底座透明、留白回到 0px，玻璃投影配方被替换；最后恢复原浅色/玻璃/灵动/标准偏好。代表截图见 glass-choice-light.png 与 glass-choice-dark.png（本轮可视化目录）。尚未扩展到 Tabs/列表状态，也未宣称全部有色主题和辅助模式验收完成。

“气质”是整套设计预设的设计方向，不是第六维或新的组件分支。预设在全局偏好层组合五维默认与角色配方，角色按功能适配；狭义材质仍是其中一维。特定预设的圆角、底色、边界、排印和运动调整只填写该预设数据，不以修改公共默认来完成。

公共默认、材质注册表、内置设计预设递归冻结；每次解析返回自己的材质角色/折射/运动快照和完整变量表，消费方不能通过结果污染其他预设或后续解析。全量输出保证反复切换覆盖上次的纹理、高光和形状参数。公共默认及能力更新仍可能影响多个预设，需要共同回归；隔离不意味着完全没有共享依赖。

新增回归覆盖五维局部修改不影响其他预设、嵌套输出互不引用、配置运行时只读，以及玻璃→纸质→实色→纸质→玻璃实际输出入口的全量替换。沿用密度/材质独立覆盖、能力回退与个人阅读保持的既有回归。本轮不改变视觉数值，后续分别打磨各套预设。

默认、液态玻璃、纸质是配置数据，组件不得判断预设 ID。纸质使用已有静态背景、边界、阴影和材质运动约束能力，验证增加预设无需复制页面或组件。折射属于引擎能力；折射强度属于参数。引擎尚不支持的全新效果仍需要先实现能力，不能通过配置凭空生成。

预设的视觉数值属于首轮可运行设计，须与工程能力和视觉最终认可区分。验证至少包括两套预设、独立维度覆盖、复合状态、切换清理、旧数据、首帧、系统回退与真实开合/导航使用处。

## 5. 代码入口与当前证据

### 卡片与折叠收敛（2026-11-01）

业务折叠统一复用 `components/ui/disclosure/Disclosure.vue`：基于已有 Collapsible + CollapseReveal，提供标题插槽、统一箭头、plain/card 变体、独立嵌套状态、受控更新、隐藏 inert 与焦点恢复。原生 details/summary 使用处已迁移，懒加载改为监听 update:open；不再分别实现箭头、点击和标题尺度。复杂组合可继续用 Collapsible 原语，状态选择器已限制到自身内容，避免祖先展开状态串入内层。

Card 使用 default/compact 规格，留白、间距、标题尺度来自五维参数。遥测卡片、来源分析、上下文、成员资料、通知及记录面板统一消费内容底面。页面只选择规格，不另外定义卡片圆角、底色或投影。主题色样本和输入分组等专门控件的边界不等同于内容卡片，不机械转换成 Card。

迁移覆盖 20 个原生折叠使用文件及 RecordPanel；通用卡片规格与折叠参数进入 component-contract。治理检查阻止重新引入裸 details/summary。统一组件不等同于整站全部设计已验收，剩余特殊组合继续按覆盖台账记录。

- `theme/component-contract.ts`：参数类型、维度归属和完整默认值。
- `theme/design-presets.ts`：默认/液态玻璃/纸质配置、差量解析、独立覆盖和能力回退。
- `theme/apply.ts`：applyAppearance 单一输出，首帧和更新共用。
- `stores/preferences.ts`、`theme/presets.ts`：预设引用、旧数据迁移、个人选择及保存组合兼容。
- `scripts/check-design.mjs`：参数登记和公共组件禁止依赖预设身份。

代码路径相对 web/src（检查脚本除外）。2026-11-01 首轮闭环已接入，验证与剩余范围见[覆盖台账](element-implementation-coverage.md)。新增预设在已有能力内填写五维配置；增加新能力才修改组件。当前支持配置文件扩展，尚无任意配置的可视化编辑器或导入协议。
