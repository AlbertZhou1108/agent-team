# 效率工作台

首页以「工作台」折叠板块承载待处理、运行活动（含最近执行标签页）与进展摘要，其后依次是数据统计和团队目录。工作台默认展开，数据统计与团队目录默认收起；工作台头部提供打开 Panel Agent 的图标入口。沿用现有主页 Surface，未增加工作流状态机或新的数据库表；折叠复用共享 Disclosure。

## 待处理与运行活动

`GET /api/workbench` 只读聚合未归档团队及全局 Panel Agent 的信息：

- 待处理仅包含 Agent 发起且仍为 pending 的互动消息；待核实运行与发送失败不计入。点击回到对应会话答复。
- 互动提醒展示 8 秒，关闭提醒不回答也不取消互动。原会话卡片及待处理中心继续保留事项，回答或核实后随状态刷新移除。
- 待处理与运行活动在同一行并排；运行活动与最近执行在同一卡片内用标签页切换，不使用嵌套折叠。
- 运行活动展示成员、团队、服务端起始时间、已运行时长和排队输入；最近执行保留最近十条记录。每两秒刷新，计时每秒更新。

## 全局搜索

侧栏入口或 Command/Ctrl+K 打开 shadcn-vue Command。无输入时展示最近访问与常用入口；键盘上下键选择、Enter 打开、Escape 关闭。

前端索引覆盖页面、设置项、团队、成员和创建团队入口。设置项通过 section/setting 定位；成员优先打开其用户会话，找不到时打开其现有会话或所属团队。创建团队只进入 Panel Agent 并在草稿为空时填入建议，不自动发送。

`GET /api/search?q=...&group=...&member=...&from=...&to=...` 查询团队消息与 Panel 私人历史。关键词按字面匹配（转义 LIKE 通配符），消息最多返回 40 条；过滤支持团队、成员、起始/截止日期，截止日期由前端换算为次日零点的排他上界。结果按页面、设置、团队、成员和消息分组，分类标签与分隔线区分各组；消息结果附摘要和定位 URL，历史页按需加载到目标消息。

Command 的本地扩展 shouldFilter=false 用于外部异步筛选，避免组件再次隐藏远端结果；默认行为保持内置筛选。

## 当前会话引用

消息菜单可引用多条已定稿消息，输入框上方显示可移除的引用块。只允许当前可写会话，切换会话清空尚未发送的引用。发送时引用以包含真实消息 id/seq、发送者和正文的文本块连同正文交付 Agent，无需额外模型调用；消息界面识别文本块并提供回原消息入口。

正文和引用合计最多 48000 字符。发送失败沿用现有草稿恢复机制，已序列化引用仍保留在草稿中，不重复附加。第一版不提供跨会话选取引用。

## 常用片段

输入框按钮或空白输入框按 `/` 打开片段列表，选择后在光标位置插入，允许继续编辑，始终手动发送。支持名称/正文新增、编辑、删除及最近使用排序。新建片段默认带入当前草稿。配置保存在本机浏览器 localStorage；与附件、引用和折叠输入框共用发送流程。

## 主页进展摘要

固定汇总全部团队，点击右上角刷新图标后走已有 Panel Agent 私人消息 API。请求以 `[主页进展摘要]` 标记，提示只读读取团队消息、附原文链接，不自动派工。此功能不改变 Panel Agent 原有权限。

工作台从既有 Panel 消息中寻找最近一次成功摘要；回复必须位于对应摘要请求与下一条用户消息之间，避免把后续普通回答误认成摘要。点击刷新立即清空旧摘要的显示，失败时恢复上一份成功结果，刷新页面和重启后仍可读取。没有配置 Panel Agent 时提供设置入口，未点击生成不会发起模型调用。

## 验证

- `test/productivity.test.mjs`：搜索字面转义/筛选/链接、仅未答复互动计数、排除运行异常和投递失败、摘要边界与保留、通过假宿主执行 Panel 摘要及幂等回放。
- `references.test.ts`：多条多行引用序列化/解析及非法文本保留。
- `interaction-notification.test.ts`：提醒导航与 8 秒时限。
- 浏览器：设置搜索跳转、异步消息搜索、会话引用与片段组合、斜杠入口。

摘要正文最高 24rem，超出后在摘要内滚动，操作按钮位于卡片右上角。

回归补充：摘要生成中的 Panel 会话没有 member_id；工作台成员查询以 null 绑定缺失身份，并使用 Panel Agent 名称。HTTP 测试在摘要执行未结束时连续轮询工作台，要求全部返回 200，结束后仍能读取新摘要。

摘要流式展示：复用 `/api/panel-agent/events` 的 SSE 通道，以 `homeSummary` 和来源消息身份区分摘要与普通私聊。点击刷新先清空正文及生成时间，读取/整理阶段只显示状态，正文到达后逐步显示新摘要；按帧合并增量并节流 Markdown 解析。完成后切换到持久摘要，断线重连通过完整快照恢复，失败或中断回退上一份成功结果。不展示推理正文。

互动待办链接只携带互动 id，进入团队完整消息流定位卡片，不使用发起互动时的成员会话过滤。旧的 session+interaction 链接会移除来源会话参数；手动切换会话时清除互动锚点。
