# 元素规格：折叠分组、导航项与内容单元

状态：2026-11-01，按用户要求拆分后的材质无关规格。本文件只描述元素是什么、包含什么、有哪些状态、响应哪些动作，以及必须满足的语义与可用性约束。**不规定配色、底色、纹理、透明度、圆角、高光、折射、动画曲线、组件选型或代码落点。**

上游：[设计逻辑框架](design-logic-framework.md)。具体呈现与代码组织见[元素实现说明](element-implementations/README.md)，接入进度与证据见[覆盖台账](element-implementation-coverage.md)。三者分别维护，不在本文件记录某种外观的实现现状。

## 1. 规格的内容与作用范围

规格以“一类元素”为单位，实例只提供具体内容与状态。同一团队出现在不同分组中，仍遵循同一种导航项规格；对象名称和所属分组不产生一份新规格。

| 字段 | 描述的信息 |
| --- | --- |
| 标识与用途 | 稳定标识、要完成的任务、适用范围和排除范围 |
| 内容与组成 | 必需/可选内容、主动作、次动作、父子及同级关系 |
| 状态 | 各状态表达的事实，哪些独立、哪些互斥、哪些可以组合 |
| 事件与转移 | 什么动作改变什么状态，什么动作不能改变什么状态 |
| 约束 | 信息可辨性、操作隔离、焦点、键盘、隐藏内容、布局稳定性 |
| 语义验收 | 与具体外观无关的可观察通过条件 |

状态不等于样式。例如“当前页面”是事实，如何突出它由实现说明决定；“展开”是状态，是否需要过渡及如何渲染由共享实现和用户动效策略决定。

外观变化不得改变上述事实和动作。每一种实现都必须满足本规格；新增一种外观不需要复制或改写本文件。只有用途、内容、状态或交互语义确实变化时，才修改元素规格。

## 2. E-GROUP：可折叠分组

### 用途与组成

用途：将相关导航对象组织成可展开和收起的集合。范围：团队文件夹、未分组、置顶；不包括整个侧栏的列宽收起。

| 内容 | 要求 |
| --- | --- |
| 分组标识、标题 | 必需；标题能够识别分组 |
| 展开状态 | 必需；表示子内容是否开放访问 |
| 子内容 | 零到多个对象；空组是否出现沿用业务规则 |
| 图标、数量、包含当前对象的提示 | 可选；不得代替必要标题或展开状态 |
| 分组菜单 | 可选；与开合动作独立 |

### 状态与转移

- 展开与收起互斥；状态与子内容是否可访问一致。
- 悬停、聚焦、拖拽目标、包含当前对象等状态与展开状态独立。
- 激活标题切换展开状态，不切换当前团队，不移动子对象。
- 激活菜单只打开菜单，不顺带开合分组。
- 若实现存在过渡，过渡中收到新开合请求应以最新目标为准；旧过程不得覆盖新状态。
- 收起包含当前对象的分组，不改变当前对象；分组本身不能被误报成当前页面。

### 约束与验收

隐藏子内容不能接收点击或键盘焦点；收起前焦点在子内容内时，应转移到有效的可见位置。标题可用键盘操作，展开状态可被辅助技术识别。内容变化和开合不得导致永久裁切或隐藏操作入口。展开状态的持久化仍遵循既有业务契约。

- G1：文件夹、未分组、置顶均有同样含义的开合动作和可访问状态。
- G2：快速切换、内容增减后，最终显示和可操作内容符合最新展开状态。
- G3：隐藏内容不可聚焦；收起后焦点仍位于可见、有效的入口。
- G4：不同外观、用户动效策略和屏幕尺寸下，上述语义保持一致。

## 3. E-NAV：导航项

### 用途与组成

用途：定位并进入某个页面或对象。范围：主页、Panel Agent、设置入口，以及所有分组中的团队项。分组标题的开合动作由 E-GROUP 描述，不自动视为页面导航。

| 内容 | 要求 |
| --- | --- |
| 导航对象标识、可读名称、目标 | 必需 |
| 是否为当前页面/对象 | 必需；与实际路由或业务选择保持一致 |
| 批量选择状态 | 使用处支持批量选择时提供；不与当前位置合并 |
| 图标、业务状态、未读信息 | 可选；独立表达各自事实 |
| 对象菜单 | 可选；与主导航动作独立 |

### 状态与组合

| 状态 | 含义与约束 |
| --- | --- |
| 当前对象 current | 当前正在查看的对象；不能只通过颜色表达 |
| 批量选择 selected | 属于待批量操作集合；不意味着正在查看该对象 |
| 悬停 / 按下 | 正在接近或激活某个动作；不能抹掉 current/selected 的含义 |
| 键盘聚焦 | 当前键盘操作位置；可以与 current/selected 同时存在且保持可辨 |
| 禁用 | 对应动作不可执行；不抹掉当前位置事实 |
| 拖拽目标 / 插入位置 | 正在进行组织操作；与当前位置和多选分别表达 |

current 与 selected 独立，允许同时为真；同一导航对象在不同位置的引用应表达相同的当前位置事实。未读、加载、错误等业务状态不得借用 current 或 selected 的含义。

### 事件、约束与验收

主导航激活进入目标；批量选择按现有选择规则改变集合；菜单动作不意外导航或改变集合。使用正确的导航/按钮/选择语义，辅助技术能够识别当前位置与可执行动作。名称截断时仍能获取完整名称；窄栏和侧栏收起时仍有可访问名称。状态切换不挤走名称或菜单，不改变操作命中区域。

- N1：同一个团队在不同分组中成为当前项时，当前位置事实和语义一致。
- N2：current、selected、悬停、按下、聚焦的组合可辨，状态之间不互相误报。
- N3：菜单与主动作相互隔离；菜单关闭后焦点恢复到有效入口。
- N4：切换外观、系统辅助偏好时，当前位置、多选、焦点和操作权限保持一致。
- N5：长名称、窄栏、收起导航及键盘操作下，必要信息与动作仍可访问。

## 4. E-CONTENT：独立内容单元

### 用途与组成

用途：将一组相关信息组织为独立、可识别的内容单元。范围：首页消耗趋势、团队消耗、团队状态及团队目录条目；不包括每个字段、代码行或消息段落。

| 类型 | 内容信息与交互差异 |
| --- | --- |
| 数据单元 | 标题、数据、口径/时间范围、数据状态、可选局部动作；不默认整单元可点击 |
| 对象目录单元 | 对象标识、名称、辅助信息、业务状态、主入口、可选排序/置顶等次动作 |

独立单元必须能与相邻单元和页面背景区分，但本规格不指定通过底色、边框、阴影、间距还是组合来实现。数据单元和目录单元不必采用相同内部结构。

### 状态、事件与约束

- 区分首次加载、正常内容、零值、暂无观测、局部失败和搜索无结果，不得用同一含混状态代替。
- 错误有可恢复动作时保留入口；刷新不应无故丢失仍然有效的内容与用户位置。
- 目录的主入口、排序、置顶各自表达不同动作；次动作不触发主导航。
- 可点击和不可点击的区域应可辨；局部动作存在不意味着整个单元可点击。
- 标题、数值、辅助信息和动作有清楚的信息层级；长名称和路径不遮挡动作、不造成页面横向溢出。
- 外观切换不改变数据含义、列表排序、行列关系或权限；不通过缩小关键文字来掩盖内容问题。

### 语义验收

- C1：数据总览和团队目录的独立信息单元均可识别，不与相邻内容混淆。
- C2：不同外观和尺寸下信息层级、可读性与操作语义保持一致。
- C3：长内容、零值、空态、无观测、失败和搜索无结果分别正确表达。
- C4：目录主入口、前移/后移、置顶分别可操作，次动作不触发主导航，键盘焦点可辨。

## 5. 变更与完成标准

修改本文件只影响语义契约，不隐含某种材质或组件已经实现。共同的语义验收 ID 由各实现引用，材质专属的视觉验收另行登记，不把“必须实色”“必须有高光”等实现选择反向写成元素定义。

一类元素完成统一需要：本规格成立、对应实现可用、列入范围的使用处完成接入、共同语义与实现专属验收均有证据。接入位置、缺口、检查结果均在[覆盖台账](element-implementation-coverage.md)维护。
