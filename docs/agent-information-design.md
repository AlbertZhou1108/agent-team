# Agent 信息访问与上下文投影

> 注:ADR 0004([通信内核优先](./adr/0004-revert-to-communication-core.md))已移除契约、工作项与目标生命周期等框架流程机制。本文中相关描述已过时,仅保留仍在实现的通信、遥测与宿主接入部分;流程相关段落以 ADR 0004 与 [README](../README.md) 为准。

日期：2026-10-24
状态：当前实现

## 目标

框架完整保存契约、消息、工作项、证据和审计记录，但 Agent 每轮默认只接收完成任务所需的信息。信息投影由确定性代码生成，不使用模型摘要代替权威事实，也不通过截断任务、规格、源码或证据来制造虚假节省。

投影只改变框架向 Agent 和工具返回的形状。权限判断、业务状态判断、接受和收尾仍以 Store、Collaboration 与 Lifecycle 中的权威对象为准。

## 信息分类

| 类别 | 默认提供方式 | 必须保留 |
| --- | --- | --- |
| 稳定规则 | 固定身份、来源、工具与权限边界 | 私聊隔离、契约上限、独立审查、责任边界 |
| 本轮事实 | 每轮重新生成的动态对象 | 当前目标、控制者 revision、实际策略、工作项 revision、阻塞和待决 |
| 当前任务材料 | 完整直接提供 | 当前规格、必要源码、触发消息和有效证据 |
| 无关历史 | 概况或稳定引用 | 明确依赖、身份未决材料、影响收尾的未处理责任 |
| 长材料 | 有界预览与 ID/hash 引用 | 完整性、续读入口和原文可恢复性 |
| 测量元数据 | 白名单字段 | schema、revision、字节数、展开次数与质量状态 |

相关性只依据明确的 `goalId`、`workItemId`、成果版本、参与责任和显式依赖。缺少身份且可能影响判断的材料进入 `unresolved`，多个工作项关联全部保留。

## 回合输入

新 schema 会话的固定规则与动态事实分离：

- 固定规则包含 Agent 身份、消息与私聊语义、权限和责任边界、独立审查、收尾及唤醒规则。
- 本轮输入包含 `contextSchemaVersion`、团队与目标身份、目标/契约/状态 revision、实际策略、当前契约、相关工作项、未决责任、待决请求、未处理正式消息、运行状态和触发消息。
- 当前任务材料与合并投递消息提供完整正文；可选历史按游标分页并显式列出 `omissions`。
- 有模型规划职责的主 Agent 上下文附带全局模型策略；普通成员规则不再常驻完整模型策略和协作快照。

动态事实每轮以当前权威状态生成。旧轮输入不是当前状态来源，恢复会话也不能让旧 revision 覆盖新事实。

## 工具读取

`read`、`team_read`、`collaboration_read` 和 `team_collaboration_read` 保持现有工具名与权限链，在新 schema 会话中采用有界视图：

- 消息列表返回 `id`、`seq`、作者、接收者、`kind`、关联、内容完整性、引用和有限预览。
- `messageId + hash + offset + bodyLimit` 展开数据库中的正文，单位固定为 Unicode code point。
- `itemId` 定向读取任意当前或历史工作项，并保留目标版本和 item revision。
- 每次范围读取重新校验端点身份、团队、当前权限、内容哈希和游标；持有旧引用不会形成永久访问权。
- `nextAfter`、`recordsHasMore`、`hasMore` 和 `complete` 明确描述当前返回范围，不代表整个团队历史完整。

成员工具、MCP stdio、Codex 动态工具和 Panel 工具共用同一投影语义。适配器只负责传输封装，不各自生成摘要规则。

## 预算与失败

默认预算定义在 `src/information.mjs`：

- 固定规则：16 KiB；
- 回合输入：512 KiB；
- 协作状态：256 KiB；
- 默认正文预览：512 code point；
- 单次正文展开：最多 4096 code point。

必要事实超过预算时明确失败，不静默截断契约、工作项、未决责任或触发消息。可选记录和输出超预算时写入 `omissions`、`complete=false` 和续读游标。规则超预算时，在宿主启动前拒绝创建回合。

这些阈值用于约束框架序列化输入，不是费用承诺。实际优化效果必须结合真实任务质量、宿主请求次数、缓存、输入/输出 token、延迟和返工评估。

## 会话兼容

没有采用新格式的原生会话继续使用原有规则和读取形状，不静默迁移或重建。新会话使用 `contextSchemaVersion=1`。显式重置会话后，下一次运行按新会话处理。

上下文格式、每轮 schema 和测量记录分别保存：

- `endpoint_context_formats`；
- `panel_session_context_formats`；
- `turn_context_schemas`；
- `information_measurements`。

测量只保存字节数、schema、目标/契约/状态 revision、分页和展开元数据，不复制消息正文、凭据或完整宿主配置。

## 当前限制

- 预算尚未按所有真实团队规模自动调优。
- Codex 动态工具入口的投影一致性通过模拟宿主协议和真实服务入口测试，不能替代每种宿主版本的模型行为验证。
- 摘要服务、向量索引、持久状态增量协议和通用内容存储库不属于当前实现。
- 原始宿主 history 仍保存既有执行审计；投影测量表不重复保存正文。
