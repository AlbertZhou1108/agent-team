# 全局数据总览

`GET /api/telemetry/overview?from=<ISO>&to=<ISO>&bucket=hour|day` 汇总全部团队的共享执行，包含归档团队，不包含私人、准备及 profile 回合。区间最长 31 天、左闭右开，归属以回合开始时间为准；分桶从区间起点开始，以固定一小时或24小时计算，不代表夏令时地区的自然日。

统计复用既有 `_buildMetrics` 的观测来源选择、累计/增量与完整度处理，按 framework batchId 去重一次；消息来源归因小计不再加入执行消耗，缓存读取是输入的子集，不与输入重复相加。观测不足保持 null；有部分数值时保留已观测合计并标记不完整。coverage 同时返回应有执行回合数、有 Token 观测回合数和缺失数。数据仍是宿主观测量，不是费用或全部后台进程消耗。

响应包含 totals、teams、series、coverage 和当前团队状态快照 states。状态互斥，依次判断：归档、待核实/blocked、运行、待确认、目标关闭、等待；状态与所选消耗时间范围分开。普通成员数量不包括独立 Panel Agent。

主页默认今天，可切换近7天、近30天，每15秒刷新；今天起点使用浏览器本地午夜，最近区间包括今天。趋势和排行展示已观测 Token，空桶使用虚线并标注无观测。趋势支持悬停预览、点击保留时段，以及键盘左右方向键、Home/End选择；选中时段显示精确Token、观测回合数和采集状态。峰值单独作为水平参考线。切换时间范围时重置选择，自动刷新时按时段起点保留选择。排行点击进入团队，来源口径保留在此接口文档中。金额不推算。

回归：`test/telemetry-overview.test.mjs` 覆盖私聊/profile排除、总量与分桶/团队合计一致、缺失观测、缓存比例、区间和粒度校验。
