# 角色状态图:各表面角色的状态与转移清单

本文是设计逻辑框架"交互状态图"的文档化落地:每个表面角色一节,列出状态(节点)、事件与转移(边)、以及每次转移改变的方面。实现时**转移终点必须落在目标状态的解析值上**(转移终点不变式,见设计逻辑框架 §6);动画渲染规格来自动效契约与材质签名。

本文记录通用状态与共享转移约定，不代表每个使用处均已接入。三类元素的状态含义与组合由[元素规格](element-specifications.md)维护，共用转移与各材质呈现见[实现说明](element-implementations/README.md)，实现差距与证据见[覆盖台账](element-implementation-coverage.md)；不引入状态机库，若转移逻辑复杂到频繁出缺陷再考虑机器可读形式。

**折叠显现原语**:未使用 reka Collapsible 的条件渲染显隐场景,统一接入 `CollapseReveal`(grid-rows 0fr→1fr,与 .collapsible-clip 同源同节奏)。**折叠显现模式的全局唯一实现 = 共享 Collapsible 或 CollapseReveal,禁止第三种**(自写 height 动画/直切)。

## 会话工作区(共享)

| 状态 | 事件 → 转移 | 改变的方面 |
| --- | --- | --- |
| 跟底 | 向上滚动超过阈值 → 显示"回到底部" | 行为(按钮入场:淡入上滑) |
| 离底 | 点击回底 / 新消息且在底部 → 回到跟底 | 行为(按钮退场;滚动) |
| 锚点定位 | URL 带 interaction/message → scrollIntoView 居中 | 布局(滚动位置),减少档直接跳转 |

## 折叠区块(共享 Collapsible)

| 状态 | 事件 → 转移 | 改变的方面 |
| --- | --- | --- |
| 收起 | 点击触发器 → 收起动画(grid-rows 1fr→0fr) | 布局(高度),随后 visibility 隐藏 |
| 展开 | 点击触发器 → 展开动画(0fr→1fr) | 布局(高度),内容可见 |

不变式:动画终点 = 目标状态的真实布局高度(逐帧解析,无测量过冲)。

## 侧栏(左导航)

| 状态 | 事件 → 转移 | 改变的方面 |
| --- | --- | --- |
| 展开 / 收起 | 点击收起按钮 → 网格列宽过渡(--motion-duration-slow) | 布局(列宽)、样式(图标/标签差量) |
| 拖拽调宽 | 指针拖动 → 列宽即时跟随(过渡暂停) | 布局(列宽,无动画) |

## 上下文面板(团队工作区右栏 / Panel Agent 右栏)

| 状态 | 事件 → 转移 | 改变的方面 |
| --- | --- | --- |
| 展开 / 收起(桌面) | 点击切换 → 网格列宽过渡 | 布局(列宽) |
| 抽屉(窄屏) | 打开/关闭 → transform 滑入滑出 + 背板淡入 | 布局(transform)、行为(过渡) |

## 会话输入区

| 状态 | 事件 → 转移 | 改变的方面 |
| --- | --- | --- |
| 空闲 / 输入中 | 用户输入 → 高度自适应 | 布局(高度) |
| 拖拽调高 | 指针拖动把手 → 高度即时跟随(过渡暂停) | 布局(高度,无动画) |
| 发送中 / 停止中 | 提交 / 停止 → 加载态 | 行为(转圈,材质签名节奏) |
| 附件拖入 | dragover → 虚线高亮(按压态) | 样式(状态层差量:--state-pressed) |

## 按钮(通用)

| 状态 | 事件 → 转移 | 改变的方面 |
| --- | --- | --- |
| 默认 → 悬停 | 指针进入 → 状态层叠加(--state-hover) | 样式(差量) |
| 悬停 → 按压 | 按下 → 缩放 0.98 + 按压层(--state-pressed) | 样式(差量)、行为(缩放过渡) |
| 禁用 | 业务置灰 → 指针事件禁用 | 样式(透明度差量) |
| 加载 | 异步进行 → 转圈替换图标 | 行为(循环,材质签名节奏) |

## 标签页(设置 / 检查面板)

| 状态 | 事件 → 转移 | 改变的方面 |
| --- | --- | --- |
| 切换 | 点击页签 → 内容重挂载入场(淡入上滑) | 行为(入场,--motion-duration-normal) |

## 通知(Toast)

| 状态 | 事件 → 转移 | 改变的方面 |
| --- | --- | --- |
| 出现 | 新通知 → sonner 内建入场 | 行为(减少档压制) |
| 自动消失 | 时间触发(倒计时) | 行为(离场;时间触发源) |

## 材质签名备注

以上"行为"列的节奏与缓动,均经动效契约解析:`风格档(能量)⊗ 材质签名(物理词汇)⊗ 用途`。玻璃签名的具体取值见主题 materials.ts 规格表;减少档一律压平。
