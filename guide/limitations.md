# 能力边界与安全

[返回产品介绍](../README.md) · [日常使用](user-guide.md) · [技术架构](architecture.md)

## 适用范围

Agent Team 是**本机、单用户**的协作环境，不提供多人账号体系、跨机器团队服务或企业级租户隔离。浏览器界面连接本机服务；模型调用可能经过外部提供商，不应把“本地运行”理解为完全离线。

v0.4.1 提供 macOS arm64、Windows x64 与 Linux x64 发行包，均未签名、未公证。源码已在三平台通过 CI，但安装包的实机验收程度以对应 Release 的说明为准。请按系统提示处理安装，不关闭安全保护。

## 宿主与费用

需要安装并配置至少一个支持的宿主。框架不代管登录、密钥、模型服务或额度，也不保证不同版本的协议永远兼容。

成员创建时的能力自述、用户聊天、成员协作和手动摘要都会产生正常模型调用。通信检测不发送模型消息，但仍可能触发宿主初始化日志或目录网络请求。统计与运行活动不是实时费用账单，也不是工作质量证明。

## 文件与执行

权限由群执行策略和宿主沙箱决定。互动卡、团队说明和角色分工都不能扩大实际权限；文件策略不代表完全网络隔离。多个成员共享工作目录时没有框架文件锁，应明确文件归属并交接，避免同时修改同一文件。

私人附件目前只支持 TXT、PNG 副本，默认 5 MiB/文件、4 文件/消息、20 MP/图片，设置可调整，服务端最终校验。不包含 PDF/Office 上传、附件转发或通用存储管理。

结果下载仅支持当前工作区内普通文件，拒绝越界与框架内部数据。归档保留记录和已发送附件；清理未发送副本不等于删除已发送内容。

## 会话、失败与恢复

目前不能接管已经在其他终端运行的宿主会话。框架创建会话并按宿主编号恢复；面板事件不是宿主全部原生历史。

Claude/DSH print/headless 模式尚未验证独立的持久入队回执，当前在成功回合返回后保守确认输入，崩溃窗口可能重发原编号。普通发送失败不自动重试；不确定运行会阻塞后续投递，必须核实宿主已停止后解除，不自动重放。

关闭网页不停止后台工作；停止服务不删除团队。私人历史按本次启动与此前记录分开显示。程序与数据分离，但不保证降级兼容；升级前停服，必要时备份完整数据目录。

## 如何理解结果

多 Agent 可以互相补充和审阅，但不能保证结论正确。任务面板、成员自述、已投递状态和消息引用分别表达不同事实，均不能替代实际验证。建议要求明确文件、依据、验证方法和未解决事项，再决定是否归档。
